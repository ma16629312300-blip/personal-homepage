# Product

## Register

brand

## Users

Visitors are classmates, friends, collaborators, recruiters, and people who receive tiaotiao's project links. They arrive with little context and should quickly understand that this is a personal homepage, a project archive, and a playful experimental space.

## Product Purpose

The site presents tiaotiao's identity, selected works, small web toys, and contact routes through a memorable interface. Success means the homepage feels personal, cinematic, and handcrafted rather than like a generic template.

## Brand Personality

Melancholic, lunar, kinetic.

## Anti-references

Avoid generic AI portfolio pages, default purple gradients, identical card grids, decorative glass panels, random neon effects, and copied game UI assets. The site may be inspired by game menus, moon phases, stairwells, archives, and clock towers, but it should not look like a direct clone of any specific game screen.

## Design Principles

1. Make the interface feel like a navigable personal space, not a decorated webpage.
2. Let moon phases, stair geometry, and clock movement drive the visual system.
3. Use Chinese as the narrative voice and English as secondary interface rhythm.
4. Prefer a few distinctive motions over many generic animated ornaments.
5. Keep every visual layer useful for mood, depth, navigation, or state change.

## Accessibility & Inclusion

Support keyboard navigation, readable contrast, responsive desktop and mobile layouts, and reduced motion preferences. Music must remain user-controlled and never autoplay without interaction.
